# Handoff — Sprint 4: MCP Registry

- **from**: Orchestrator
- **to**: MCP Adapter / Governance
- **intent**: continuar a integração do catálogo compartilhado com clientes MCP.
- **context**: o MCP agora descobre capabilities visíveis no registry, descreve definições e expõe
  transporte local JSON-RPC por stdio via `forja mcp:start`.
- **acceptance**: manter ferramentas dinâmicas alinhadas ao registry, validar payload no registry,
  preservar identidade/policy e testar clientes que enviam mais de uma mensagem no mesmo chunk.
- **constraints**: não duplicar handlers; não colocar regra de domínio no transporte; não tratar
  stdio como autenticação remota; GraphLoop persistente e approvals MCP seguem pendentes.
- **return**: próxima sprint deve integrar catálogo padrão no server/MCP e decidir persistência de
  auditoria MCP, com teste de contrato para SDK/MCP.

## Entregas

- `forja mcp:start`;
- `forja_capability_describe`;
- ferramentas dinâmicas para as seis capabilities migradas;
- framing por linha e resposta JSON-RPC estruturada;
- testes MCP atualizados.
