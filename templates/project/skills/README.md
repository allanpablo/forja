# Skills do projeto

Instaladas pelo `forja project:wire` em `.claude/skills/` (Claude Code) e `.agents/skills/` (Codex).
Cada pasta tem um `SKILL.md` com frontmatter (`name`, `description`); o `name` é igual ao nome da pasta.

## Origem

As skills de produto, requisitos, design, qualidade, TypeScript, segurança, operações, entrega, IA,
compliance, comunicação e git vêm do skill ledger de Allan Pablo (`allus-co/my-skill-ledger`),
traduzidas para pt-BR, com a trilha de Go convertida para TypeScript e publicadas no Forja sob a licença
MIT com autorização do autor. As seções "No Forja" são a integração com o processo do Forja.
`llm-provider-routing` é do próprio Forja.

Para atualizar a partir do ledger: copie as skills e reaplique as seções "No Forja" (ADR-0089).
